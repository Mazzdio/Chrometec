# Chrometec – Sistema de Gerenciamento de Empréstimos de Chromebooks

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) no CEEP.PLG.

## Sobre o projeto

O Chrometec é um sistema desenvolvido para auxiliar no gerenciamento dos empréstimos e devoluções de Chromebooks na instituição de ensino, permitindo organizar os acessos de alunos, professores e administradores.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Funcionalidades

- Autenticação de usuários;
- Cadastro de alunos;
- Gerenciamento de alunos e professores;
- Consulta e gerenciamento de empréstimos;
- Controle de devoluções;
- Gerenciamento do inventário de Chromebooks.

## Estrutura do projeto

O sistema utiliza uma arquitetura cliente-servidor, com interfaces desenvolvidas em HTML, CSS e JavaScript, processamento das operações por meio de PHP e armazenamento das informações em banco de dados MySQL.

## Finalidade

Este repositório disponibiliza o código-fonte desenvolvido para fins de documentação e avaliação acadêmica do Trabalho de Conclusão de Curso.
